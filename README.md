# Sea Radar

Навчальна локальна карта суден у Дуврській протоці. Це не навігаційний інструмент. Після кожного запиту відображається знімок на момент отримання; вибірка може бути неповною. Автоматичного оновлення немає.

## Вимоги

- Node.js 24 і npm.
- Встановлені залежності проєкту з `package-lock.json`.
- Для браузерних тестів — Chromium, встановлений Playwright.

## Встановлення та запуск

1. Клонуйте репозиторій і відкрийте його кореневу теку.
2. Встановіть залежності командою `npm ci`.
3. Щоб увімкнути запити AISStream, локально задайте `AISSTREAM_API_KEY` у `.env.local`. Це необов'язково: без ключа карта продовжує показувати демонстраційні судна. Не додавайте локальні env-файли чи значення ключа до Git, повідомлень або звітів.
4. Запустіть `npm run dev` і відкрийте <http://localhost:3000>.

Якщо Next.js не може завантажити нативний Turbopack binding на вашому Windows-комп'ютері, запустіть `npm run dev -- --webpack`.

## Запит AISStream

- Запит запускається вручну кнопкою **«Завантажити справжні позиції»**. Перед ним можна вибрати вікно збору: 15, 30, 60, 120, 180, 240 або 300 секунд.
- Прапорець **«Малі судна (клас B)»** розширює підписку; за замовчуванням він вимкнений. Налаштування не зберігаються після перезавантаження сторінки.
- Під час запиту кнопка стає **«Скасувати»**. Шкала показує орієнтовний перебіг вибраного часового вікна, а не кількість суден у реальному часі. Вікно може завершитися раніше, якщо досягнуто ліміту 100 суден; після завершення вікна шкала чекає на відповідь API.
- Після непорожньої успішної відповіді панель показує кількість отриманих суден, час знімка, вибране вікно та статус повноти вибірки. Розділ **«Докладно»** містить час з'єднання, лічильники повідомлень і відкинутих записів.
- Порожній результат не означає, що в районі немає суден. При помилці чи порожньому результаті попередній показаний набір залишається на карті; результат останньої спроби показується окремо. Скасування очищає набір і не повертає часткові дані. Лише непорожній успіх замінює показаний набір.
- Після перезавантаження сторінки знову показуються демонстраційні дані. Сирий текст помилок провайдера й секретні значення в інтерфейсі не показуються.

## Перевірки

За потреби встановіть Chromium для Playwright командою `npx playwright install chromium`, потім виконайте з кореня проєкту:

```sh
npx playwright test
npx tsc --noEmit
npm run build
```

Якщо нативний Turbopack недоступний через політику Windows, замість останньої команди виконайте `npm run build -- --webpack`.

Playwright-тести підміняють відповідь локального `/api/snapshot`; вони не підтверджують доступність AISStream. Збірка й тестування не вимагають ключа.

## Результати останньої перевірки

- `npm run dev` — сервер запустився; локальні запити з вікнами 15 с (клас B вимкнено) і 60 с (клас B увімкнено) повернули HTTP 200.
- `npx playwright test` — 85/85 пройшли.
- `npx tsc --noEmit --pretty false` — пройшов без помилок.
- `npm run build` — успішно згенерував `/`, `/_not-found` і `/api/snapshot`.
- `npm ci`, `npx playwright install chromium` і попередня перевірка `npm audit` виконані успішно; у звіті аудиту після оновлення `source-map-js` було 0 вразливостей.

## Обмеження даних

- Судна AISStream отримуються лише після натискання кнопки; між запитами їхнє положення не анімується.
- За один запит збирається обмежене часове вікно; набір може бути обмежений лімітом і не є повним переліком суден у районі.
- Невдала або порожня спроба не означає, що попередні судна залишаються актуальними: підпис на карті показує час отримання саме показаного набору, а рядок спроби — час і результат останнього запиту.
- Після перезавантаження сторінки збережені AIS-знімки не відновлюються.
