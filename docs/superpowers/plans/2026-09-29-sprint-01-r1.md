# Sea Radar R1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the Sprint 01 R1 slice: a local Dover Strait map with three labeled demo vessels, selectable vessel cards, finite route movement, and Playwright selection tests.

**Architecture:** Keep one shared `Vessel` model and one parent-owned vessel/selection state so markers and the card always render the same current vessel. Keep agreed map/timing constants in one config module, route literals and pure movement/formatting logic separate from UI, and initialize Leaflet only in a client effect; do not add a server/API layer or a second map wrapper library.

**Tech Stack:** Node.js 24; TypeScript 6.x (`strict`); Next.js App Router + React; Leaflet 1.9.x; OpenStreetMap Standard tiles; Playwright Test as the only test runner.

**Spec:** `docs/tasks/SPRINT-01.md`; cross-check: `docs/PROJECT_BRIEF.md` and `ABOUT.md`.

## Global Constraints

- Use Node.js 24, TypeScript 6.x with `strict`, Next.js App Router + React, Leaflet 1.9.x, and Playwright Test as the only test runner.
- Keep application source under `src/`, including the App Router at `src/app/`; keep project configuration at the repository root.
- Load Leaflet JavaScript only in the browser; do not add React-Leaflet or another map library.
- Use OSM Standard tiles at `https://tile.openstreetmap.org/{z}/{x}/{y}.png` and show attribution `© OpenStreetMap contributors`.
- Fixed area: rectangle from 50.75° N, 0.95° E to 51.25° N, 1.95° E; initial center 51.00° N, 1.45° E; zoom 10.
- Keep agreed map and timing values in a single configuration module.
- Use the specified vessel fields: `id`, `name`, `lat`, `lon`, `speedKnots`, `courseDeg`, `timestamp`, `source`; demo IDs are `demo-1`…`demo-3`; empty names become `null`; zero and `null` remain distinct.
- Preserve card formatting exactly: coordinates with `toFixed(5)`; speed to one decimal maximum with no trailing zero and `kn`; course `Math.round % 360` with `°`; time as `HH:MM:SS UTC`; unknown values as `Немає даних`; source labels `Демонстраційні дані` / `AISStream`.
- Provide three demo vessels, each with 8–12 in-area route points and a literal speed; use `DEMO_TICK_MS = 2000`; calculate course as the great-circle initial bearing of the segment; use browser time for timestamps; stop at the final point with speed `0` on the arrival tick; refresh starts from the beginning.
- Bind the dev server to loopback and serve `http://localhost:3000`; do not expose the app to the LAN.
- This sprint has no AIS connection, real-data button, server/API scaffolding, pause, rewind, looping, history, search, filters, auth, cloud deployment, or future-feature placeholders.
- The movement check is visual/manual in this sprint. The Playwright suite tests selection and blocks tile requests; it does not automate movement with a controlled clock.
- Review each B-task diff against its acceptance criteria before moving on. Checkpoint records contain only observed facts and actual command results.
- End every commit message with the exact trailer `Co-Authored-By: Claude Code <noreply@anthropic.com>`.

## Review Focus

1. **Client-only map lifecycle:** direct route load, refresh, and viewport resize must leave one correctly sized map without SSR errors, duplicate layers, or visual artifacts. Manual check in Task 2; `next build` is also required there.
2. **Untrusted and absent names:** `null`, empty, and `<b>Демо</b>` must render as plain text or `Немає даних`, never as HTML. Manual check in Task 4.
3. **Unknown versus zero and numeric boundaries:** `null` speed/course must not become zero; `0 kn` remains a real value; a course that rounds to 360 displays `0°`. Manual check in Task 4.
4. **Selection consistency:** repeated marker click and map-background click must not clear selection; while the selected demo vessel moves, the card must show its latest state. Manual check in Task 4 and browser checks in Task 7.
5. **Timer lifecycle and route end:** one shared 2-second interval updates all vessels; hot reload must not duplicate ticks; reaching the final point sets speed to zero on that same tick and later leaves that vessel unchanged. Manual check in Task 6; do not add controlled-time movement tests.
